# 3-minute professional demo script

## Goal

Show how the Supply Chain Kanban AI Agent turns a disruption into a governed, auditable operational response.

## 1) Open the Kanban Command Board

Start with the board. Explain that every card is a supply-chain risk case, not a generic task.

Message:

```text
This board shows the full operating loop: signal, triage, mitigation, approval, execution, and audit.
```

## 2) Select the highest-risk case

Open a card with high risk and show affected resource, owner, SLA, impact, recommendation, and evidence.

Message:

```text
The agent explains what is affected, why it matters, and what action it recommends.
```

## 3) Review approval gate

Show the pending action and explain why human approval is required.

Message:

```text
High-impact actions do not execute silently. They route through policy and approval.
```

## 4) Simulate or execute governed action

Run dry-run first, then execute if approved.

Message:

```text
Execution is typed, connector-scoped, idempotent, and receipt-producing.
```

## 5) Show audit timeline and receipt

Close with request ID, decision, connector response, and evidence timeline.

Message:

```text
The team can prove what happened, who approved it, what changed, and why.
```
